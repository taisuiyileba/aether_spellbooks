# 地牢宝库与守卫召回

地牢 boss 死后留下守卫之魂，用圣物恢复房间并召回 boss；藏宝箱转化为立体宝库。默认每位参战者直接获得一把对应钥匙，每位玩家可独立消耗一把钥匙开启一次，互不占用领取资格。Boss 复活后重置房间内宝库，下一次击杀继续给参战者分发钥匙。每次开启仍会把整份战利品一次性弹出。

## 规则

只处理属于地牢的 boss，即天境在生成 boss 房模板时写入了房间追踪器（`BossRoomTracker`）的滑行魔石、武神女王和烈阳巨灵。刷怪蛋、`/summon` 或其他模组刷出的 boss 没有追踪器，掉落和原版完全一致。天境自己的 `die()` 和铁魔法的刷怪蛋死者之王也按这一标准区分。

| 时机 | 行为 |
|---|---|
| 玩家第一次走进 boss 房 | 按天境拆房时遍历的范围，记录所有会被拆掉的方块：锁定石砖、boss 门和藏宝门。房间数据保存在维度存档（`GuardianLairs`）中，不依赖任何实体 |
| boss 死亡（`LivingDeathEvent`，最低优先级，未被取消） | 天境已在 `die()` 里先拆房，此时只在该 boss 自己的房间范围内，把“仍上锁且内容未生成”的藏宝箱换成同类宝库，沿用箱子原来的战利品表和朝向；已开过或手动放了物品的箱子不动 |
| 掉落（`LivingDropsEvent`） | 房间里有宝库且 `keyPerParticipant=true` 时，取消原本的一把地牢钥匙掉落，按参战 UUID 每人直接发一把到背包；跨维度的玩家也能领取，离线、尚未重生或背包已满时保留待领取奖励。天境原本的雕纹石、金剑、太阳祭坛等其他掉落完整保留。没有宝库或关闭该项时保持原版的一把地面钥匙 |
| 玩家开启宝库 | 每次消耗一把对应钥匙，为该玩家独立生成一份战利品并记录其 UUID；同一人本轮再次尝试不会消耗钥匙，也不会重复发奖。其他玩家仍可使用自己的钥匙领取 |
| boss 死亡后 | 留下守卫之魂，飘回 boss 出生点等待 |
| 使用圣物 | 对灵魂使用，或在已攻克的房间内使用。仪式持续 4.5 秒：房间由外向内恢复，藏宝门最后关闭，随后 boss 带着原来的名字和房间回到出生点；`resetVaultsOnRevival=true` 时清空本房间宝库的领奖记录，所有玩家都能在下一轮领取 |
| 复活的 boss 被击败 | 钥匙分发规则与首次击杀一致，每位参战者再获得一把；天境原本击杀该 boss 会掉落的物品照常掉落。玩家用新钥匙领取下一轮宝库奖励 |

藏宝箱在 boss 死亡前一直被藏宝门封住，而藏宝门不可破坏，所以生存模式下玩家看到的始终是宝库。这样做不改天境的结构代码，老存档里尚未攻克的地牢同样生效；卸载本模组后，未攻克地牢里的仍是原版藏宝箱。

## 恢复房间时的保护

- 只恢复仍是 boss 死亡后状态（解锁石砖、空气、活板门或可替换方块）的位置，玩家之后放置的方块和容器不会被覆盖。
- 有生物站着的位置跳过，避免把人卡进墙里。
- boss 门恢复为打开状态，和开战前一样。
- 藏宝室里有玩家时拒绝开始仪式（没有宝库时按藏宝箱定位藏宝室，两者都没有时取藏宝门周围 2 格）；仪式中途若有人进入，藏宝门保持打开，等 boss 再次倒下。
- 灵魂丢失（例如被指令清除）时，在房间内使用圣物会重新生成灵魂，不会让地牢永久失效。

天境 boss 的特殊处理：

- 武神女王的快照、恢复和拆房范围均覆盖整座银牢，包含首领房外的锁定石砖与陷阱石砖；圣物代替 10 枚胜利奖牌，召回后她直接接受挑战（`readyUp`）。
- 滑行魔石只能撞碎不在 `aether:slider_unbreakable` 里的方块，而这个标签依赖“锁定”石砖。如果不恢复锁定石砖，复活的滑行魔石在开启生物破坏时会撞穿墙壁，因此仪式会完整恢复房间。
- 烈阳巨灵死亡时会结束天境的永昼，召回不改变这个状态。

三种宝库都加入 `aether:slider_unbreakable`，并禁止生物破坏，避免复活的滑行魔石撞毁宝库。待领取钥匙保存在主世界的 `aether_spellbooks_dungeon_keys` 数据中；在线玩家每秒尝试领取一次，已发放的钥匙会从待领取记录中移除。

## 物品与来源

| 物品 | 用途 | 来源 |
|---|---|---|
| 守卫残片 | 合成圣物 | 三座地牢宝库每次开启 2～4 个；两座神殿箱子 60% 概率 1～3 个；两种术师 30% 概率掉落（受抢夺影响） |
| 岗哨核心 | 召回滑行魔石 | 4 守卫残片 + 4 圣石 + 紫晶块 |
| 武神誓约 | 召回武神女王 | 4 守卫残片 + 4 胜利奖牌 + 金锭（武神术士掉落胜利奖牌） |
| 烈阳余烬 | 召回烈阳巨灵 | 4 守卫残片 + 4 金琥珀 + 火焰符文（烈阳祭司掉落两者） |
| 雕纹 / 天灵 / 狱炎宝库 | 每人每次重置可用对应钥匙独立开启一次 | 由藏宝箱转换；创造模式物品栏可直接放置（默认使用天境的地牢奖励表） |

天境的地牢奖励通常会掷出十几组小堆物品。本模组的三种地牢宝库会先合并相同物品，再于开启瞬间一次性弹出；领奖记录会保存到存档，退出重进也不能重复领取。默认在 boss 复活时重置；关闭 `resetVaultsOnRevival` 后，复活不再清空记录。

针对原本铁魔法的宝库（骸骨宝库、狱烬宝库等），本模组提供了可选的兼容增强：
- **一次性弹出**：开启铁魔法宝库时，同样在瞬间一次性弹出整份合并后的战利品。
- **复活 Boss 刷新宝库**：同时开启 `resetVaultsOnRevival` 时，使用死者之王命匣复活死者之王，会刷新灵魂周围水平 64 格、上下 32 格内的宝库；召唤天境守卫则刷新其首领房间内的宝库。
- 此兼容通过独立配置项 `modifyIronsSpellbooksVaults` 控制，**默认关闭**。关闭时，天境守卫复活也不会改动房间内铁魔法自带宝库的领奖记录。

## 配置

`config/aether_spellbooks-common.toml`：

```toml
[dungeons]
treasureChestsBecomeVaults = true
keyPerParticipant = true
resetVaultsOnRevival = true
guardianRevival = true
modifyIronsSpellbooksVaults = false
```

`keyPerParticipant` 控制每人一把并直接放入背包；关闭后保留天境的一把地面钥匙。`resetVaultsOnRevival` 控制复活是否清空领奖记录。两项均默认开启；宝库始终按玩家分别记录领取资格。

## 实现位置

| 文件 | 内容 |
|---|---|
| `dungeon/DungeonVaultBlock`、`VaultTier` | 三种立体宝库，继承铁魔法 1.20.1 移植的 `VaultBlock`，不可破坏、不可炸毁，每人每轮独立开启一次 |
| `dungeon/DungeonVaults` | 藏宝箱转换、查找宝库、清空已领奖记录、合并并一次性弹出全部战利品、刷新区域宝库 |
| `dungeon/Guardians`、`GuardianKind` | 参战者记录、死亡、按参战者分发钥匙（保留天境原版 boss 其他掉落）与圣物召回 |
| `dungeon/DungeonKeyRewards`、`event/DungeonEvents` | 跨维度钥匙发放、离线或背包已满时保留奖励，以及玩家 tick 补发 |
| `dungeon/GuardianLair(s)`、`RoomSnapshot`、`RoomRestorer` | 房间存档、快照和恢复 |
| `entity/GuardianSoul`、`client/GuardianSoulRenderer` | 守卫之魂、仪式和光柱，仪式完成时刷新房间内宝库 |
| `mixin/BlockEntityTypeAccessor` | 把三种宝库加入铁魔法宝库方块实体的有效方块，否则不会 tick 和同步 |
| `mixin/VaultRewardsAccessor`、`VaultEjectionMixin` | 保留每位玩家的领奖记录，并在解锁瞬间一次性弹出合并后的全部战利品（支持铁魔法宝库配置联动） |
| `mixin/DeadKingSoulMixin` | 玩家使用命匣复活死者之王时刷新地下墓穴宝库 |
| `tools/dungeon_art.py` | 宝库立体模型与贴图、圣物、灵魂贴图（带 `--check`） |

## 验证

- `ASDungeonGameTests`（20 项，单独批次 `dungeon`）：藏宝箱安全转换；召唤的 boss 不受影响；多人直接领钥匙及关闭配置后的原版掉落；跨维度、离线和背包已满时的领取与保存；双人各开一次、忙碌时不吞钥匙、同人重复开启被拒绝、存档保留领取记录、完整召回后重置与二次分发；天境原版其他掉落；房间恢复和藏宝室保护；三种宝库抵御真实滑行魔石撞击；女王整座银牢恢复；铁魔法兼容与重置开关组合，以及真实死者之王灵魂交互时的刷新行为。
- `ASB_RENDER_CHECK=dungeon ./gradlew runClient`：三种宝库的空闲、激活与俯视画面，日夜两种光照下的灵魂，召回仪式，以及背包图标。选取的截图见 `docs/screenshots/dungeon_*.png`。
